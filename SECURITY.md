# Security policy

Report vulnerabilities privately to the repository owner; do not open public issues for them. Before publication, replace this sentence with a monitored security contact.

PayBridge V0.1 intentionally does not accept, process, store, or log PANs, CVV/CVC, magnetic-stripe data, or equivalent authentication data. Use hosted checkout or provider-generated payment-method tokens. Treat provider secrets, access tokens, webhook signing secrets, and full payloads as sensitive.
